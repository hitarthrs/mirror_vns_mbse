# analysis_tools_n_models

Domain modules in progress for Mirror VNS analysis.

**plasma_physics** — plasma source parameterisation based on FBIS (beam-ion distribution, injection angle, axial neutron source shape).

**tritium_management** — tritium breeding and transport in the PbLi breeder (OpenMC production, FESTIM inventory / concentration).

**thermal_hydraulics** — 1-D PbLi loop thermal-hydraulics (axial temperature, flow, pressure drop, pump work).

**costing** — plant costing via PyFECONS / TEA (CAS tables, LCOE).
